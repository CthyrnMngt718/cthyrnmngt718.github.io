RHU MORONG HEALTH SYSTEM

Designing an operational interface around healthcare workflows.

UI/UXFront-EndPHP / MySQLTeam Project
01
PROBLEM

Dense information had to remain usable.

Healthcare personnel needed a clearer way to work with patient intake, appointments, and record-management tasks without forcing every action into the same visual priority.

02
WORKFLOW

Structure followed the order users actually work.

Related information was grouped around workflow stages so primary actions, status, and supporting details were easier to scan and understand.

03
INTERFACE

Hierarchy came before decoration.

Forms, records, and management screens were organized to reduce competing visual signals and preserve readability as information density increased.

03 / UI·UX

INTERFACE THINKING

How I think through interface and usability decisions.

I start with the user’s task, the information they need, and the next action. From there, I organize the layout and make sure it still works when the screen gets smaller.

Patient arrivesRecord lookupInformation reviewService / consultationRecord update
User concern

Operational users need fast access to information without navigating through unnecessary screens.

Interface response

Group information by task and keep primary actions visually distinct from secondary metadata.

Responsive response

Dense desktop layouts should reorganize into readable stacked states instead of simply shrinking.
