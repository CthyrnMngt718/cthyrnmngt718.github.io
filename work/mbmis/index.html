Menguito Businesses MIS

A full-stack management information system built to bring Menguito Businesses operations, records, services, assets, collections, financial information, and role-based workspaces into one secure web platform.

CONTEXT / PROBLEM

Why this project mattered

Business information and recurring operational tasks needed one organized system without giving every user the same tools or access.

USERS

Who the system serves

Authorized staff and administrators working across Menguito Businesses operations and management workflows.

MY RESPONSIBILITY

Full-stack development

I worked across the responsive interface, PHP application workflows, MySQL-backed data handling, role-aware account access, validation, system modules, deployment, and iterative maintenance.

DESIGN / DEVELOPMENT DECISIONS

Reasoning behind the system

  • Organize modules around assigned responsibilities instead of exposing every function at once.
  • Keep account access and security feedback clear and predictable.
  • Use reusable navigation, layout, and component patterns as modules grow.
  • Keep operational data readable across desktop and smaller screens.
CHALLENGE

What made it difficult

Combining multiple business functions while keeping permissions, navigation, data workflows, and interface behavior consistent as the system expanded.

RESPONSE

How I approached it

I structured the system around reusable modules and role-based workflows, connected front-end states to database-backed operations, and refined behavior through testing and deployment updates.

OUTCOME / STATUS

What happened

The system is deployed online and available as the active Menguito Businesses Management Information System.

Technology: HTML · CSS · JavaScript · PHP · MySQL · Bootstrap

WHAT THIS PROJECT STRENGTHENED

Full-stack thinking beyond a single screen.

MBMIS strengthened how I connect interface decisions with server-side behavior, database workflows, role-based access, deployment, security checks, and ongoing maintenance as one development process.
