Angono NHS Career Assessment

A web-based career guidance tool for incoming Senior High School students to explore suitable SHS strands using interests, skills, and academic inclinations.

Visit live projectDiscuss an opportunityDownload resume
CONTEXT / PROBLEM

Why this project mattered

Students needed a more structured digital way to reflect on possible strand choices and receive guidance based on assessment inputs.

USERS

Who the interface served

Incoming Senior High School students and school personnel supporting the assessment process.

MY RESPONSIBILITY

Where I contributed

Independent development of the database, front-end, system features, and deployment across the full project lifecycle.

DESIGN / DEVELOPMENT DECISIONS

Reasoning behind the work

  • Keep the assessment flow sequential and easy to understand.
  • Use progressive disclosure so users focus on one decision at a time.
  • Make results clear enough to support discussion rather than appear as an opaque score.
  • Keep the interface usable on typical student devices.
CHALLENGE

What made it difficult

Owning multiple layers of the application independently while keeping the assessment flow and data handling consistent.

RESPONSE

How I approached it

Built the interface, database, and core features together around one clear user journey, then refined behavior through testing and deployment.

OUTCOME / STATUS

What happened

Successfully assessed 50+ students and supported more informed academic decision-making.

Technology: HTML · CSS · JavaScript · PHP · MySQL · Bootstrap

WHAT I WOULD IMPROVE TODAY

Growth is part of the case study.

A future version could use stronger analytics, improved accessibility testing, and more formal validation of assessment content with school guidance professionals.
